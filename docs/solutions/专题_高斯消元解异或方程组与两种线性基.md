# 高斯消元解异或方程组 与 两种线性基

> 专题文章 · 面向 XCPC / OI
>
> 关键词：GF(2) 线性代数、增广矩阵、线性基（插入型 / 对角化型）、最大异或、第 k 小异或

本文分三部分：

1. **异或方程组的高斯消元**：把 `x1 ^ x2 ^ ... = b` 形态的方程组化为增广矩阵，用 bitset 做高斯消元，判断无解与自由元个数，得到解的数量与一个特解。
2. **两种线性基**：深入讲清楚两套常用形态——**插入型（阶梯形）线性基** 与 **对角化（简化阶梯形）线性基**，各自的构造、性质与应用。
3. **两者的联系**：线性基本质上就是对"一组异或向量"做高斯消元，两种形态只是约化程度不同。

文中涉及代码均为 C++17 风格（`long long` 下按 62 位版本编写，扩展到 `unsigned long long` / 63 位同理）。

---

## 一、异或方程组与高斯消元

### 1.1 问题定义

有 $n$ 个方程、$m$ 个未知数，每个方程形如：

```
a11 x1 ^ a12 x2 ^ ... ^ a1m xm = b1
a21 x1 ^ a22 x2 ^ ... ^ a2m xm = b2
...
an1 x1 ^ an2 x2 ^ ... ^ anm xm = bn
```

其中 $x_j, a_{ij}, b_i \in \{0, 1\}$，`^` 为异或。所有运算都在 **GF(2)**（模 2 加法域）上进行。

典型场景：

- 开关灯问题（按一个开关翻转若干盏灯，求能否全灭 / 方案数）；
- 网格染色、奇偶性约束问题；
- 图论中判断某组边能否构成特定奇偶性的割 / 环。

### 1.2 转成增广矩阵

每一行对应一个方程：前 $m$ 个元素是系数 $a_{i1}..a_{im}$，最后一个元素是常数 $b_i$。

**行变换只有一种**：把某一行异或到另一行上（对应两个方程相加）。这就是高斯消元在 GF(2) 上的全部操作。

```cpp
// a[i][j] : 第 i 个方程, j 列
// a[i][m] : 常数 b_i
// 返回是否可解; freeVar 得到自由元个数
const int MAXN = 1005;
bitset<MAXN> a[MAXN];          // 每一行用一个 bitset

bool gauss(int n, int m, int &freeVar) {
    int r = 0;                                  // 当前已经确定的行数(秩)
    for (int col = 0; col < m && r < n; ++col) {
        // 1. 找第 col 列系数为 1 的一行
        int piv = r;
        while (piv < n && !a[piv][col]) ++piv;
        if (piv == n) continue;                 // 该列全是 0 -> 自由列(自由元)
        swap(a[piv], a[r]);                     // 2. 换到第 r 行
        for (int i = 0; i < n; ++i) {           // 3. 消去其他所有行的这一列
            if (i != r && a[i][col]) a[i] ^= a[r];
        }
        ++r;                                    // 秩 +1
    }
    // 4. 无解判定: 某行系数全 0 但常数是 1 -> 0 = 1
    for (int i = r; i < n; ++i)
        if (a[i][m]) return false;

    freeVar = m - r;                            // 自由元个数
    return true;
}
```

说明：上面第 3 步连"上方行"一起消，得到的是**简化阶梯形（RREF）**——每个主元列上只有一个 1，主元行就是该列。这样求特解特别方便：

- 若第 $r$ 行的主元在第 $j$ 列，则 $x_j = a[r][m]$；
- 自由列对应的变量随便取 0 / 1，就得到不同的解。

### 1.3 解的三种情况

| 情况 | 判定 | 解的数量 |
|---|---|---|
| 无解 | 存在"系数全 0 但常数 = 1"的行 | 0 |
| 唯一解 | 可解且 `freeVar == 0` | 1 |
| 多解 | 可解且 `freeVar > 0` | $2^{\text{freeVar}}$ |

特解 + 自由元任意取值，就覆盖了所有解。

### 1.4 复杂度

- 朴素 Gauss（每行是 `long long`，$m \le 63$）：$O(n \cdot m \cdot \min(n,m))$；
- bitset 版本：方块消元部分被压缩到 $\frac{1}{64}$：
  $$O\!\left(\frac{n \cdot m \cdot \min(n,m)}{64}\right)$$
- 空间：$O(n \cdot m / 8)$ 字节。

当 $n, m$ 达到 $10^3 \sim 10^4$ 量级（例如 P2447 外星千足虫那种 $n \le 1000, m \le 2000$ 的大数据），**必须用 bitset**。

### 1.5 典型应用题

- **P2447 【SDOI2010】外星千足虫**：异或方程组 + bitset，还要求最早读入几条信息就能确定解（按顺序插入行，模拟到秩满 / 出现矛盾为止）。
- **POJ 1681 / P2557 开关问题类**：开关灯异或方程组，求自由元个数与方案数。
- **图论奇偶性 / 边割问题**：把"每条边在哪些约束里出现"编码成二进制向量，直接套方程组。

## 二、两种线性基

### 2.0 动机与定义

**异或线性基**：一个（可重）多重集 $S \subseteq \{0,1\}^k$（元素可看作 $k$ 位二进制向量），所有子集的异或构成 GF(2) 上的一个线性子空间 $V$。选取尽量少的向量 $b_1, b_2, \dots, b_r$，使它们的异或组合恰好张成 $V$，就得到 $V$ 的一组**基**，$r = \dim V$ 称为**秩**。

**核心思想：数字化高斯消元**。把每个数的第 $i$ 位看成"第 $i$ 列 1"，线性基的建立过程就是高斯消元的向量版本。

于是自然地出现两种构建 / 两种形态。**"两种线性基"在竞赛圈通常指下面两种存放基底的形式**：

| | 第一种：插入型（阶梯形） | 第二种：对角化型（简化阶梯形） |
|---|---|---|
| 构造方式 | 逐个插入,$O(B)$ / 次 | 对已有基做高位消元,$O(B^2)$ |
| 基的形态 | $b_i$ 的最高位 = $i$，各主元位唯一出现在自己的向量里 | 每个 $b_i$ 除了主元位外，**低位上的主元位也被清掉**（类似 RREF） |
| 主打应用 | 求最大异或、判断可表示、在线动态插入 | 求第 $k$ 小异或值、求排名（rank） |
| 在线能力 | 可随时插入 | 插入后若要 $k$ 小需重建，但重建也很便宜 |

（$B$ 为位数，一般 $B = 62$。）

### 2.1 第一种：插入型（阶梯形）线性基

**存储**：`p[i]` 表示"最高位恰好为 $i$ 的基向量"。约定 $p[i] = 0$ 表示该位空。

**插入算法**（从高到低尝试消掉 $x$ 的最高位）：

```cpp
// 每一位的最高位有一个「主人」向量
struct Basis {
    long long p[63];                  // p[i]: 最高位为 i 的基向量

    long long add(long long x) {      // 插入 x, 返回化剩下的残量(0 表示 x 已被张成)
        for (int i = 62; i >= 0; --i)
            if (x >> i & 1) {
                if (!p[i]) { p[i] = x; return x; }
                x ^= p[i];            // 第 i 位已经有主, 把它消掉
            }
        return 0;
    }
    // 若想顺便得到秩, 数一下 add 返回非 0 的次数即可
};
```

为什么是对的：每一步保证 $x$ 的最高位递减；要么 $x$ 在某位遇到空位而成为新基向量（并保持最高位 = 该位），要么 $x$ 一路被消成 0，说明它可由现有基组合表示。**基内两两"主元位互不相同，最高位互不相同"**，因此它们线性无关。

时间复杂度：单次插入 $O(B)$，插入 $N$ 个数 $O(NB)$。

#### 应用 A：求最大异或和

```cpp
long long maxXor() {
    long long ans = 0;
    for (int i = 62; i >= 0; --i)
        ans = max(ans, ans ^ p[i]);   // 第 i 位只有 p[i] 能改变, 遇到 1 就翻
    return ans;
}
```

贪心正确性：主元位 $i$ 只会被 $p[i]$ 影响。从高到低看，若 $ans$ 的第 $i$ 位是 0 而 $p[i]$ 存在，异或上 $p[i]$ 一定把这一位变 1 且不破坏更高位，因此一律取。

**注意**：最大异或问题里的起点可以是任意给定的 `init`（如给定初始状态求最大加成），把 `ans` 初始化为 `init` 即可——因为 `init` 异或任意子集就是"从 init 出发"的全体。

#### 应用 B：判断一个数能否被表示 / 是否属于空间

```cpp
bool contain(long long x) {
    for (int i = 62; i >= 0; --i)
        if (x >> i & 1) x ^= p[i];    // 顺着主元位一路消
    return x == 0;
}
```

思路：从高到低，第 $i$ 位为 1 时必须使用 $p[i]$（只有它管理第 $i$ 位），消完若归零说明可表示。复杂度 $O(B)$。

#### 应用 C：两个基合并（求并/并空间）

```cpp
void merge(const Basis &o) {          // 把另一个基的所有向量插入进来
    for (int i = 62; i >= 0; --i)
        if (o.p[i]) add(o.p[i]);
}
```

复杂度 $O(B^2)$。树剖 + 线性基合并、可持久化线性基都是这个套路。

### 2.2 第二种：对角化（简化阶梯形）线性基

#### 重建（rebuild）

在插入型的基础上再做一轮"高位消元"：对每个基向量 $p[i]$，用更低的基向量 $p[j]$（$j < i$）把它的低位主元位全部清掉。结果满足：**主元位 $i$ 只出现在 $p[i]$ 自己里**（其他向量里该位为 0）——这是"简化阶梯形"的位向量版。

```cpp
struct Basis {
    long long p[63];
    long long q[63];                  // 重建后的对角向量, 按主元位升序
    int cnt = 0;                      // 基的大小(秩)

    void rebuild() {
        for (int i = 62; i >= 0; --i)              // 从高到低
            for (int j = i - 1; j >= 0; --j)
                if (p[i] >> j & 1) p[i] ^= p[j];   // 清掉 p[i] 的低位主元
        cnt = 0;
        for (int i = 0; i <= 62; ++i)
            if (p[i]) q[cnt++] = p[i];             // 主元位升序收集
    }
};
```

为什么从高到低：当处理 $p[i]$ 时，$p[j]$（$j<i$）还没被改，仍保持"最高位 = $j$"，用它异或不会碰 $p[i]$ 的最高位 $i$，能干净地消掉第 $j$ 位；即使异或带入了更低位的 1，也会在后续 $j$ 递减的循环里被再次清除。最终每个主元位在整个基中只出现一次。

这个形态下有一个优美性质：**枚举下标 $t \in [0, 2^{cnt})$，令第 $t$ 个可表示值**
$$
v(t) = \bigoplus_{i:\, \text{bit }i\text{ of }t = 1} q[i],
$$
则 $v(0)<v(1)<\dots<v(2^{cnt}-1)$ **严格递增**。理由：从大到小看 $t$ 的最高不同位 $i$，$v$ 中对应的主元位也恰好是第一个不同的位，而 $q[i]$ 独占该主元位。

#### 求第 k 小异或值

利用上面的单调性，第 $k$ 小（1-indexed）就等于 $v(k)$（下标 $k$ 按上面 $v(t)$ 的定义），逐位用 `k` 的二进制决定取不取 $q[i]$：

```cpp
// dep: 原集合是否线性相关(即 元素个数 > 秩, 插入时出现过 add() 返回 0)
//      → 存在非空子集异或为 0, 0 必须计入排名
long long kth(long long k, bool dep) {        // k: 1-indexed
    if (dep) --k;                             // 0 计入排名, 整体下标前移 1
    if ((unsigned long long)k >= (1ull << cnt)) return -1;  // 超出空间大小
    long long ans = 0;
    for (int i = 0; i < cnt; ++i)
        if (k >> i & 1) ans ^= q[i];          // v(k): 下标二进制里为 1 的位对应取 q[i]
    return ans;
}
```

**关于 0 的边界处理**（为什么先 `--k`）：

- 空集异或永远是 0，但"非空子集异或"能否凑出 0 取决于原集合是否线性相关；
- **线性相关**（元素个数 $>$ 秩，即插入时有数被完全消掉）→ 0 是一个合法取值，排名时 0 算第 1 小，所以 `--k`；
- **线性无关** → 可表示值只有 $2^{cnt} - 1$ 个（排除空集），下标 $k$ 直接从 1 开始；
- 两种情况下下标 $k$ 的取值范围都是 $[0, 2^{cnt}-1]$，用无符号比较判断越界，同时规避 `1LL << 63` 的未定义行为（符号类型左移溢出）。

#### 求 rank（排名）

给一个数 $x$，问它是可表示值全集中从小到大第几个：把它用对角基拆解，等于从 $cnt$ 位下标 $t$ 改写成整数排名——对每个参与拆解的 $q[i]$ 加上 $2^i$ 即可。

```cpp
long long rankOf(long long x) {       // 前提: x 可表示; 返回 0-indexed 排名
    long long rk = 0;
    for (int i = 0; i < cnt; ++i) {
        int pos = __lg(q[i]);         // q[i] 的主元位 = 它的最高位
        if (x >> pos & 1) {           // 主元位上的 1 只能来自 q[i]
            rk |= (1LL << i);
            x ^= q[i];
        }
    }
    return rk;                        // 0-indexed, 加 1 得 1-indexed 排名
}
```

实现细节：对角化基中 $q[i]$ 独占其主元位（即最高位），从低位到高位扫描每个 $q[i]$，若 $x$ 在该主元位为 1，则这一位只能由 $q[i]$ 贡献，在排名里加上 $2^i$ 并把 $x$ 与 $q[i]$ 异或掉。

### 2.3 两种形态的对比与选择

| 能力 | 插入型 | 对角化型 |
|---|---|---|
| 动态插入 | $O(B)$，即插即用 | 插入后需 $O(B^2)$ 重建 |
| 最大异或 | 贪心 $O(B)$ | 贪心 $O(B)$ |
| 可表示性判断 | $O(B)$ | $O(B)$ |
| 第 $k$ 小 / rank | 不支持（需先 rebuild） | 直接 $O(B)$ |
| 合并 | $O(B^2)$ | 合并后需重建 |

**使用建议**：

- 只求最大异或 / 判断可表示 / 需要大量在线插入 → 第一种；
- 求第 $k$ 小、排名、权衡下需要"简化阶梯形"的性质 → 第二种；
- 很多题两者都行（如"最大异或"两套都能写），但 **`insert` 是 $O(B)$ 的现实成本，两种都保留一份模板最稳**。

### 2.4 典型应用题

- **P3812 【模板】线性基**：最大异或。第一种即可。
- **P4151 【WC2011】最大异或和路径**：无向图任意起点终点路径的最大异或。图的性质：一条通路 + 若干个环 = 另一条通路（以起点终点为锚），所以**路径异或 = 任意一条简单路径异或 ^ 所有环的异或（可自由组合）**。DFS 建环、原路异或建基，答案 = 初始路径值异或基中最大可加值。
- **P4570 [BJWC2011] 元素**：价值最大化 = 按价值降序贪心，能插入就选；维护一个线性基判断"是否与已选向量无关"。
- **P3292 [SCOI2016] 幸运数字**：树链查询点权异或空间的 max，线段树 / 倍增维护线性基的合并。
- **P3857 [TJOI2008] 彩灯**：开关向量构成的空间大小 = $2^{\text{秩}}$，数秩即可。
- **第 k 小异或**：SPOJ 的 XOR 类经典题 / 洛谷 P4151 拓展。

## 三、两者是同一件事：线性基 = 高斯消元

把"异或方程组"与"线性基"放在一起看，会发现它们完全同构：

- 方程组高斯消元的**行** = 线性基的**基向量**；
- 消元过程 = 用主元行消掉其他行的主元列；
- 自由元（列） = 未被主元覆盖的位；
- 秩 = 非零主元个数；
- **插入型线性基** = 对向量集合做"从上到下、见 1 就消"的增量高消；
- **对角化线性基** = 高消最后一步（把主元列以上的位置也清干净），即 RREF。

甚至能把题目互相转化：

- "序列子集异或能凑出哪些数 / 最大 / 第 $k$ 小" → 线性基；
- "若干约束求方案数" → 增广矩阵高斯消元，方案数 = $2^{\text{自由元}}$；
- 两者数据规模都小（$m \le 62$ 或 $n, m \le 10^3$），都是"位运算线性代数"，是 XCPC 里性价比极高的送分 / 送套路题。

## 四、复杂度一览

| 操作 | 复杂度 |
|---|---|
| 高斯消元（$n$ 方程 $m$ 未知数，bitset） | $O(n\cdot m\cdot \min(n,m)/64)$ |
| 线性基单次插入 | $O(B)$ |
| 线性基最大异或 / 可表示判断 | $O(B)$ |
| 线性基重建（对角化） | $O(B^2)$ |
| 第 $k$ 小 / rank | $O(B)$ |
| 两个基合并 | $O(B^2)$ |

空间：高斯消元 $O(nm/8)$ 字节；线性基 $O(B)$，恒为常数。
