# agc_028B Removing Blocks 题解

## 题意

有 $n$ 块砖排成一行，第 $i$ 块的重量为 $arr_i$。每次操作可以选择一块**尚未被消除**的砖块将其消除，获得的收益为**当前与它连通的所有砖块**（即包含它的那一段连续存活区间）的重量之和，被消除的这块自身也计入。

例如 $arr=\{3,5,2,1\}$：先消除 $5$，收益 $3+5+2+1=11$，数组变为 $\{3,X,2,1\}$；再消除 $1$，它与 $2$ 连通，收益 $2+1=3$，数组变为 $\{3,X,2,X\}$；再消除 $2$，收益 $2$；最后消除 $3$，收益 $3$。该方案总收益为 $11+3+2+3=19$。

一共有 $n!$ 种消除顺序，求**所有**消除顺序的收益总和，答案对 $10^9+7$ 取模。

数据范围：$1\le n\le 10^5$，$1\le arr_i\le 10^9$。

## 核心思路

算法类型：**贡献法（交换求和顺序）+ 笛卡尔树（祖先与高度）+ 线性求逆元**。

**记号约定：** 下文一律用**编号**（下标）指代砖块——"编号 $i$"指下标为 $i$ 的那一块，$arr_i$ 是它的值。切勿把编号与值混为一谈：在 $arr=\{3,5,2,1\}$ 中，值 $5$ 属于编号 $2$，值 $2$ 属于编号 $3$。（题意部分沿用题面"按值称呼砖块"的说法，只因该例中值两两不同，才不致混淆。）另外记 $f(i)=\sum_{j=1}^{i}\frac{1}{j}$，即调和数。

**（一）总转化链：从"枚举方案"到"每个位置的祖先数期望"**

一共 $n!$ 个消除方案，逐个枚举不可能。第一步把总收益按位置拆开——方案收益是所有被计入的值之和，交换求和次序即按砖块归并：

$$\text{总收益}=\sum_{\text{方案}}\sum_{i=1}^{n}\bigl(\text{编号 }i\text{ 在该方案中被计入的贡献}\bigr)=\sum_{i=1}^{n}arr_i\cdot c_i$$

其中 $c_i$ 是编号 $i$ 在全部 $n!$ 个方案中被计入的总次数。$c_i$ 只与消除顺序有关，于是写成期望的形式：

$$\text{总收益}=n!\times\sum_{i=1}^{n}arr_i\times \mathbb{E}\bigl[\text{高度}(i)\bigr]$$

$n!$ 是方案总数，$\mathbb{E}$ 表示均匀随机消除顺序下的期望。于是问题归结为一句话：**求每个编号在笛卡尔树上的高度期望**。下面三步走：（二）说明"收益为什么等于 值 $\times$ 高度"，（三）求"$x$ 是 $i$ 的祖先"的概率，（四）对 $x$ 求和。

**（二）建树：中序用编号、堆序用删除时间、节点携带值**

给每个编号记下它的**删除时间** $t_i$（第几个被消除），于是 $(t_1,t_2,\dots,t_n)$ 是 $1\sim n$ 的一个排列。每个节点携带三个字段：

| 字段 | 含义 |
| --- | --- |
| 节点值 | $arr_i$ |
| 编号 | $i$ |
| 删除时间 | $t_i$ |

以**编号**为中序、以**删除时间**为键，建一棵**小根**笛卡尔树——删除时间越小（越早被消除）的节点越靠上，树根就是第一个被消除的块。

**为什么"编号 $i$ 的收益 = 节点值 $\times$ 高度"？** 因为消除过程本身就等于这棵树按堆序的递归分裂：根最先被删，它一被拿掉，序列就断成左右两段，恰好是左右两棵子树；此后每删一块，就是把它所在子树的区间再劈开一次。具体地，删除编号 $k$ 时：

- **子树区间之内**：$k$ 的子树所管辖的编号区间 $[L_k,R_k]$ 里，除 $k$ 外每个点的删除时间都比 $t_k$ 大，也就是**都还没被删**；
- **子树区间之外**：$L_k-1$ 与 $R_k+1$（若存在）的删除时间都比 $t_k$ 小，也就是**都已经删掉**，连通性在此被切断。

所以删除 $k$ 时，$k$ 所在的连通段恰好就是它的子树区间，这一步的收益 = 该子树区间的节点值之和。

再把每一步的收益按节点归并：$arr_i$ 被累加的次数 = **管辖区间包含编号 $i$ 的节点个数** = **$i$ 的祖先个数（含 $i$ 自己）**。于是

$$\text{高度}(i)=\text{祖先数}(i)+1$$

其中"祖先数"指**真祖先**的个数，根的高度为 $1$。这正是（一）里那条式子。

**（三）核心概率：$x$ 是 $i$ 的祖先的概率**

设 $x\le i$，则

> **$x$ 是 $i$ 的祖先 $\iff$ $x$ 在编号 $x,x+1,\dots,i$ 这 $(i-x+1)$ 个块中**最先**被消除。**

**注意措辞**：不是"$x$ 比 $i$ 先被消除"——那种情况的概率是 $1/2$；而是"$x$ 比中间**所有**块都先被消除"。只有 $x$ 与 $i$ 之间没有更早被删的块，$x$ 与 $i$ 才不会被切断，$x$ 才会落在 $i$ 的祖先链上。

**计数**：只看这 $(i-x+1)$ 个编号，它们的相对先后顺序等可能，共 $(i-x+1)!$ 种；其中 $x$ 排第一的有 $(i-x)!$ 种。剩下 $n-(i-x+1)$ 个块无论怎么排都不影响这件事，分子分母各自相乘后约掉：

$$p=\frac{(i-x)!\times(\text{其余块的排列数})}{(i-x+1)!\times(\text{其余块的排列数})}=\frac{(i-x)!}{(i-x+1)!}=\frac{1}{i-x+1}$$

**例子**：取 $n=9,\ x=2,\ i=6$。只看编号 $2,3,4,5,6$ 这 $5$ 个块，共 $5!$ 种相对顺序；其中 $2$ 最先的占 $4!$ 种（其余 $4$ 块随便排），故 $p=4!/5!=1/5$。若误读成"$2$ 比 $6$ 先删"，则会数出 $5!/2=60$ 种、概率 $1/2$，与后面的调和数对不上。

同理，当 $x\ge i$ 时把区间换成 $i..x$，得到 $p=\dfrac{1}{x-i+1}$。

**（四）对 $x$ 求和：调和数，以及"$-2$"和"$-1$"的来历**

把 $x$ 按落在 $i$ 的左侧还是右侧分成两段：

- **左侧** $x=1,\dots,i-1$：概率为 $\frac{1}{i-x+1}$。令 $d=i-x+1$，则 $x$ 从 $i-1$ 减到 $1$ 时 $d$ 从 $2$ 增到 $i$，故
  $$\sum_{x=1}^{i-1}\frac{1}{i-x+1}=\sum_{d=2}^{i}\frac{1}{d}=f(i)-1$$
- **右侧** $x=i+1,\dots,n$：同理，$d=x-i+1$ 从 $2$ 增到 $n-i+1$，故
  $$\sum_{x=i+1}^{n}\frac{1}{x-i+1}=\sum_{d=2}^{n-i+1}\frac{1}{d}=f(n-i+1)-1$$

两段相加：

$$\mathbb{E}\bigl[\text{祖先数}(i)\bigr]=f(i)+f(n-i+1)-2$$

（两个 $-1$ 的来历：左右两段的求和都从 $d=2$ 起步，各缺一个 $\frac11$——缺掉的正是"$x=i$ 是 $i$ 的祖先"这件必然事件。也正因为把它排除在外，这里数的是**真祖先**。）

再加上节点自身，高度期望为

$$\mathbb{E}\bigl[\text{高度}(i)\bigr]=f(i)+f(n-i+1)-1$$

代回（一），得到最终答案：

$$\boxed{\ \text{answer}=n!\times\sum_{i=1}^{n}arr_i\bigl(f(i)+f(n-i+1)-1\bigr)\ }$$

**（五）完整例子**

取 $6$ 块砖：

```
编号 i     :  1   2   3   4   5   6
节点值      :  3   6   2   4   9   2
删除时间 t  :  6   3   4   1   5   2
```

即消除顺序为编号 $4\to6\to2\to3\to5\to1$。按"中序为编号、小根堆为删除时间"建树：

```
                        编号4  值4  时间1
                      /                    \
          编号2  值6  时间3              编号6  值2  时间2
            /            \                   /
 编号1 值3 时间6   编号3 值2 时间4   编号5 值9 时间5
```

各节点的子树区间与高度：

| 编号 | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ |
| --- | --- | --- | --- | --- | --- | --- |
| 子树区间 | $[1,1]$ | $[1,3]$ | $[3,3]$ | $[1,6]$ | $[5,5]$ | $[5,6]$ |
| 高度 | $3$ | $2$ | $3$ | $1$ | $3$ | $2$ |

**先验证"每步收益 = 子树区间和"**：

| 步 | 删除编号 | 该步连通段 | 段内值和 | 对应节点的子树区间 |
| --- | --- | --- | --- | --- |
| 1 | $4$ | $[1,6]$ | $3+6+2+4+9+2=26$ | 编号 $4$：$[1,6]$ |
| 2 | $6$ | $[5,6]$ | $9+2=11$ | 编号 $6$：$[5,6]$ |
| 3 | $2$ | $[1,3]$ | $3+6+2=11$ | 编号 $2$：$[1,3]$ |
| 4 | $3$ | $[3,3]$ | $2$ | 编号 $3$：$[3,3]$ |
| 5 | $5$ | $[5,5]$ | $9$ | 编号 $5$：$[5,5]$ |
| 6 | $1$ | $[1,1]$ | $3$ | 编号 $1$：$[1,1]$ |
| | | | **合计 $62$** | |

两列逐行一致，正是（二）的结论。**再验证"收益 = 值 $\times$ 高度"**：

| 编号 $i$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ |
| --- | --- | --- | --- | --- | --- | --- |
| 节点值 $arr_i$ | $3$ | $6$ | $2$ | $4$ | $9$ | $2$ |
| 高度 | $3$ | $2$ | $3$ | $1$ | $3$ | $2$ |
| 贡献 | $9$ | $12$ | $6$ | $4$ | $27$ | $4$ |

合计 $9+12+6+4+27+4=62$，与逐步模拟完全吻合。

**（六）模意义下的调和数与代码对应**

$f(i)=\sum_{j=1}^{i}\frac{1}{j}$ 含除法，在模 $p=10^9+7$ 下要改成乘逆元。由于 $p$ 是素数且 $n\le 10^5<p$，每个 $j$ 的逆元都存在。用线性递推 $O(n)$ 一次打出整张逆元表：

$$\mathrm{inv}[1]=1,\qquad
\mathrm{inv}[i]=-\left\lfloor\frac{p}{i}\right\rfloor\cdot \mathrm{inv}[p\bmod i]\pmod p$$

再对逆元表做一次前缀和，即得 $\mathrm{sum}[i]=f(i)\bmod p$，最后把 $n!$ 也补上。代码与公式的对应关系：

- `inv[i]` ← 线性逆元表；
- `sum[i]` ← 调和数 $f(i)$（注意 `sum[1] = 1` 即 $f(1)$；循环从 $i=2$ 开始，所以这一项要手动初始化）；
- `res += (sum[i] + sum[n - i + 1] - 1) * arr[i]` ← $\sum_i arr_i\bigl(f(i)+f(n-i+1)-1\bigr)$；
- 最后 `for (i = 1..n) res = res * i % mod` ← 乘上 $n!$。

**（七）实现要点：不要把 $n!$ 存下来**

不要先把 $n!$ 显式算出来存进 `long long` 再乘。$n!$ 在 $n\ge 21$ 时已超过 $2^{63}-1$；更隐蔽的是，当

$$v_2(n!)=\left\lfloor\frac n2\right\rfloor+\left\lfloor\frac n4\right\rfloor+\left\lfloor\frac n8\right\rfloor+\cdots\ge 64$$

（即 $n\ge 66$）时 $n!\equiv 0\pmod{2^{64}}$，存进 64 位整数的阶乘会**恰好变成 $0$**，导致答案恒为 $0$。像本代码这样在模意义下边乘边取模才是安全的。

```cpp
// 
#include <iostream>
#include <cstring>
#include <cstdio>

#include <unordered_map>
#include <cmath>
#include <numeric>
#include <sstream>
#include <array>
// 支持lcm函数
#define LL long long
#define ULL unsigned long long
#define pair_int std::pair<int, int>
#define pair_LL std::pair<LL, LL>
const int INF_INT = 0x3f3f3f3f;
const LL INF_LL = 1e18;
const LL mod = 1e9 + 7;
const int MAXL = 0;
using std::cin;
using std::cout;
using std::endl;
using std::vector;
#define endl '\n' // 交互题记得去掉

void solve()
{
    // std::cout << std::fixed << std::setprecision(2);
    // std::cout.unsetf(std::ios::fixed);

    LL n;
    cin >> n;

    vector<LL> arr(n + 1, 0);
    vector<LL> sum(n + 1, 0);
    vector<LL> inv(n + 1, 0);

    for (LL i = 1; i <= n; i ++) {
        cin >> arr[i];
    }

    inv[1] = 1;
    for (LL i = 2; i <= n; i ++) {
        inv[i] = (mod - (mod / i) * inv[mod % i] % mod) % mod;
    }

    sum[1] = 1;
    for(LL i = 2; i <= n; i ++) {
        sum[i] = (sum[i - 1] + inv[i]) % mod;
    }

    LL res = 0;

    for (LL i = 1; i <= n; i ++) {
        res = (res + (sum[i] + sum[n - i + 1] - 1) % mod * arr[i] % mod) % mod;
    }
    
    for (LL i = 1; i <= n; i ++) {
        res = res * i % mod;
    }

    cout << res << endl;

    return;
}

int main()
{
    std::ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int _ = 1;
    // cin >> _;
    for (int i = 0; i < _; i ++)
    {
        solve();
    }
    return 0;
}
```

## 复杂度

- 时间复杂度：$O(n)$。算法不需要真的建出笛卡尔树，只需线性求逆元、求调和数前缀和、统计答案、乘 $n!$，各为一次线性扫描。
- 空间复杂度：$O(n)$，用于 `arr`、`inv`、`sum` 三个长度为 $n+1$ 的数组。
