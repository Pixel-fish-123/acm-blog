# P1377 [TJOI2011] 树的序 题解

## 题意

按题目给定的规则，把 $k_1,k_2,\dots,k_n$ 依次插入一棵初始为空的二叉查找树：插入 $k$ 时，若 $k$ 小于当前子树根的键值就进入左子树，否则进入右子树，直到走到空位置成为新叶子。

能生成同一棵 BST 的插入序列都称为这棵树的**生成序列**。现在给出其中一个生成序列（$k_1\sim k_n$ 是 $1\sim n$ 的排列），要求输出与它生成同一棵树的所有生成序列中**字典序最小**的那个。

数据范围：$1\le n\le 10^5$，时限 1s，内存 128MB。

样例：输入 `4` 与 `1 3 4 2`，输出 `1 3 2 4`。

## 核心思路

一句话结论：**答案是原 BST 的前序遍历。**

下面四步依次回答：哪些序列能生成同一棵树、字典序最小意味着什么、为什么它恰好是前序、以及怎么用 $O(n)$ 把这棵树建出来。

### 一、生成序列 = 树上"祖先先于后代"偏序的线性扩展

固定一棵形态已知的 BST，一个插入序列 $p_1,p_2,\dots,p_n$（$1\sim n$ 的排列）能生成它，当且仅当：

> 每个节点在序列中都排在它在这棵树里的**所有后代**之前。

**必要性**：插入 $k$ 时，查找路径从根一路比较下去，必然经过 $k$ 最终位置的全部祖先。所以 $k$ 被插入时它的每个祖先都已经在树里了，即祖先在序列中出现得更早。

**充分性**：设序列满足上述条件，归纳说明它生成的就是原树。插入 $v$ 时，$v$ 的所有祖先都已在树上，查找过程于是沿着 $v$ 在原树中的那条路径一路向下走（每一层的走向由键值与当前节点的大小关系决定，而原树中 $v$ 的祖先恰好给出同样的走向），一直走到 $v$ 的父亲处；此时 $v$ 该占的那个儿子位置一定是空的——能占住它的节点，键值必然落在该位置对应的子树区间内，也就是 $v$ 在原树中的后代，而它按条件排在 $v$ 之后、此刻还没插入。所以 $v$ 恰好落在原树中它的位置上。

两个方向合起来：**生成序列恰好是"祖先指向后代"这张偏序图的全体线性扩展（拓扑序）**。注意条件只需对父亲成立即可，因为祖先关系是父亲关系的传递闭包。

**方向不要搞反**：这里成立的是"**祖先 $\Rightarrow$ 更早插入**"，反过来（"更早插入 $\Rightarrow$ 是祖先"）**不成立**。样例 `1 3 4 2` 里 $4$ 比 $2$ 先插入，但 $4$ 是 $3$ 的右儿子、$2$ 是 $3$ 的左儿子，两者互不为祖先。精确的判据见第五节第 2 条。

### 二、字典序最小的拓扑序：每步取最小的可选节点

把"父亲已经输出"的节点称为**可选**节点。用一个经典结论：

> 反复从可选集合中取出**键值最小**的节点输出，得到的序列就是字典序最小的拓扑序。

交换论证：设某个最优解这一步输出的是 $x$，而当前可选集合中的最小者是 $m<x$。$m$ 的父亲此刻已经输出，所以把 $m$ 移到这里、其余元素相对顺序不变，仍然是一个合法拓扑序（$m$ 的约束已满足，别的元素的先后关系没被改动）；但两个序列第一个不同的位置上，前者是更小的 $m$，矛盾。因此每步都必须取最小可选者，归纳即得结论。

### 三、在 BST 上，这个贪心就是前序遍历

记 $T_u$ 为以 $u$ 为根的子树，并注意 BST 的键值性质：$T_u$ 左子树里所有键值 $<$ $u$ 的键值 $<$ 右子树里所有键值。

对子树归纳证明：上述贪心会先完整输出左子树，再输出右子树，也就是**根 → 左子树 → 右子树**的前序。

走到 $u$ 之后，可选集合里的点来自两处：$T_u$ 内部已输出节点的儿子，以及 $u$ 的祖先另一侧的那些节点（例如 $u$ 在某个祖先的左子树里，那么这个祖先的右儿子也可能可选）。后者的键值比 $T_u$ 里任何键值都大；而前者当中，只要左子树还没输出完，左子树里就必定存在可选节点（已输出的节点在子树内构成一个下闭集合，若还有没输出的，就必有某个"父亲已输出、自己没输出"的节点）。于是贪心会一直只在左子树内部取点，直到左子树整体输出完毕；由归纳假设，左子树内部的顺序正是它自己的前序。左子树走完后，同样的论证给出右子树的前序。

所以原树的**前序遍历**就是字典序最小的生成序列。用样例验证：`1 3 4 2` 建出的树是根 $1$、右儿子 $3$，$3$ 的左右儿子为 $2$ 和 $4$，前序 $1,3,2,4$ 与答案一致。

### 四、$O(n)$ 建树：它是一棵笛卡尔树

直接按序模拟插入最坏是 $O(n^2)$——排列递增时树退化成一条右链，每次插入都要从根走到叶子。

换个视角：给每个键值 $k$ 记下它的插入时间 $t(k)$（在输入中的下标），每个节点就对应一个二元组 $(k,t(k))$。原树在 $k$ 维满足 BST 性质，在 $t$ 维满足小根堆性质（祖先必定先于后代插入，父亲自然先于儿子）；**同时满足这两条的树是唯一的**，它就是二元组 $(k,t(k))$ 的笛卡尔树（可以类比成"把关键字换成 $k$、优先级换成 $t$ 的 Treap"，这只是类比，严格论证见下）。于是不必模拟插入，直接用笛卡尔树的单调栈建树模板。

**数组必须"翻过来"喂**。笛卡尔树的 BST 性质是由它的 **in-order 维**给出的——中序是什么顺序，它就是"以什么为键"的 BST。原序列天然给的是 `a[i] = k_i`（下标 = 时间、值 = 键值），两个维度恰好装反：

- 照搬模板（in-order 维 = 下标、堆维 = 数组值 $k_i$）：建出来的是**下标-BST**，中序是插入的时间顺序而非键值顺序，根本不是原树；
- 把下标当作堆维：下标严格递增，最小值永远在最左，建出来恒为一条右链，毫无信息。

所以要先做一次"值 $\leftrightarrow$ 时间"对调，写成 `val[k] = t(k)`，让 in-order 维变成键值、堆维变成时间。这也正是代码里 `val[x] = i` 那一行的意义。

**为什么"两条性质"能唯一确定一棵树**（上一段的证明骨架）：记 $\mathrm{val}[k]=t(k)$，并约定子树的中序是完整中序的一段（因此每棵子树的节点集必是一个连续的键值区间 $I$）。

- **存在**：递归定义 $T(I)$——$I=\{l..r\}$ 取 $m=\arg\min_{k\in I}t(k)$ 为根，左子树递归 $T(\{l..m-1\})$、右子树递归 $T(\{m+1..r\})$。对 $|I|$ 归纳：中序显然是 $l..r$；$m$ 是 $I$ 内 $t$ 最小者，故 $t(m)$ 小于两个子区间内任何点的 $t$，配合归纳假设知每条父子边都满足"父的 $t$ 更小"。
- **唯一**：设某棵树满足这两条，取它的任一子树 $S$（节点集为区间 $I$，根为 $r_S$）。$r_S$ 是 $I$ 中每一点的祖先，于是 $t(r_S)<t(v)$ 对一切 $v\in I,\ v\ne r_S$ 成立，即 $r_S=\arg\min_{k\in I}t(k)$——**根被唯一确定**；又因中序严格递增，"中序 = 左子树 + 根 + 右子树"迫使左子树恰好是键值小于 $k_{r_S}$ 的那一段、右子树是大于它的那一段——**左右划分也被唯一确定**。对 $|I|$ 归纳，整棵树唯一。
- **收口**：$T^*$ 满足这两条（中序为 $1\sim n$ 来自 BST 不变式，父先于子来自查找路径），而满足这两条的树唯一，所以 $T^*$ 就是 $\mathrm{val}$ 的笛卡尔树。
- 唯一性用到 $t$ **两两不同**（本题 $t$ 是排列）；若允许并列的 $t$，唯一性不再成立。

按键值 $k=1,2,\dots,n$ **递增**扫描（这保证中序恰为 $1\sim n$，即 $k$ 维的 BST 性质），用栈维护当前树的**最右链**：栈底是整棵树的根，自底向上键值与 $t$ 都递增。处理键值 $i$（记 $t_i=t(i)$）时：

1. 弹出栈顶所有 $t$ 比 $t_i$ 大的节点，并记住**最后一个**被弹出的节点 `last`。这些节点键值比 $i$ 小且 $t$ 比 $t_i$ 大，说明它们比 $i$ 后插入，不可能再是 $i$ 的祖先；它们整体构成 $i$ 左子树里最靠右的一段。
2. 弹完后若栈非空，栈顶 $j$ 满足 $t_j<t_i$ 且 $j<i$，即它是 $i$ 左边最后一个比 $i$ 先插入的点。在"已经扫过的键值"范围内，$i$ 应当接在它右边，于是把 $i$ 接成 $j$ 的**右儿子**。（这只是暂定：若之后出现一个键值更大、$t$ 更小的点，$i$ 会在那一步被弹出并改挂成它的左儿子——这与笛卡尔树原本的刻画"父亲是左右两侧最近的更小 $t$ 中 $t$ 较大者"一致。）
3. 把 `last` 挂成 $i$ 的**左儿子**：刚被弹掉的那段键值都比 $i$ 小、$t$ 都比 $t_i$ 大，恰好是 $i$ 左子树的右链，其中键值最大的 `last` 离 $i$ 最近，就是这棵左子树的根。
4. $i$ 入栈。

扫描结束后栈里剩下的是整棵树的右链，**栈底就是根**。从根做一次前序 DFS 输出即可，每个节点入栈、出栈各一次，建树是线性的。

以样例 $k=(1,3,4,2)$ 为例，$t(1)=1,\ t(3)=2,\ t(4)=3,\ t(2)=4$：

| 处理 $i$ | 比较 | 动作 | 栈（底→顶） |
| --- | --- | --- | --- |
| $1$ | 栈空 | 无父、无左儿子 | $1$ |
| $2$ | $t_2=4>t_1=1$ | $2$ 是 $1$ 的右儿子 | $1,2$ |
| $3$ | $t_3=2<t_2=4$ | 弹出 $2$，$3$ 是 $1$ 的右儿子，$2$ 是 $3$ 的左儿子 | $1,3$ |
| $4$ | $t_4=3>t_3=2$ | $4$ 是 $3$ 的右儿子 | $1,3,4$ |

栈底 $1$ 即根，前序 $1\to3\to2\to4$，输出 `1 3 2 4`，与样例一致。

### 五、五个容易踩的坑

1. **把方向搞反**：成立的是"祖先 $\Rightarrow$ 更早插入"，不是"更早插入 $\Rightarrow$ 是祖先"。样例里 $4$ 比 $2$ 早，两者却是兄弟；若"更早即祖先"成立，任意两点就都有祖孙关系，树只能退化成一条链，与样例矛盾。
2. **以为"早"就够了**：$u$ 是 $v$ 的祖先的充要条件是

   $$u \text{ 是键值区间 } \bigl[\min(k_u,k_v),\ \max(k_u,k_v)\bigr] \text{ 内 } t \text{ 最小的元素}.$$

   由它还能读出一个三分法：区间内 $t$ 最小者是 $u$，则 $u$ 是 $v$ 的祖先；是 $v$，则反过来；若是第三人 $w$，则两者互不为祖先，且 $w$ 就是它们的 LCA。样例里的 $4$ 与 $2$ 正是最后一种——中间的 $3$ 更早，把两人分进了两棵子树。直觉：两人键值之间只要夹着一个更早插入的点，这个人就把两人切开了。这条判据也解释了单调栈为什么只需要"栈顶"和"最后一个被弹出的点"这种邻域信息。
3. **把"笛卡尔树满足 BST"说漏限定词**：笛卡尔树确实满足 BST 性质，但**键是它的 in-order 维**（中序是什么顺序，键就是什么顺序）。所以判断标准不是"它是不是 BST"——两类喂法建出来的都是合法的 BST——而是"**它的 in-order 维是不是键值顺序**"。
4. **把前序当成"另一种贪心"**：前序不是贪心动作，而是"每步取最小可选节点"这个贪心在 BST 上的**等价结果**。两个保证分工明确：**堆性质**（祖先先于后代）保证它合法、按它插入建出来还是原树，**BST 的键值性质**（左子树全体键值小于右子树全体）保证它字典序最小。
5. **搞混 `val` 的两个角色**：`val[x] = i` 里，$x$ 是键值（扫描顺序、in-order 维），$i$ 是插入时间（堆维，比较的对象）。扫描按键值 $1\sim n$ 递增，比较的是 `val` 的值；两者写反就会建出下标-BST。

## 参考代码

```cpp
// 
#include <iostream>
#include <cstring>
#include <cstdio>
#include <algorithm>
#include <vector>
#include <queue>
#include <iomanip>
#include <string>
#include <map>
#include <stack>
#include <set>
#include <bitset>
#include <random>
#include <unordered_map>
#include <cmath>
#include <numeric>
#include <sstream>
#include <array>
// 支持lcm函数
#define LL long long
#define ULL unsigned long long
#define pair_int std::pair<int, int>
#define pair_LL std::pair<LL, LL>
const int INF_INT = 0x3f3f3f3f;
const LL INF_LL = 1e18;
const LL mod = 998244353;
const int MAXL = 0;
using std::cin;
using std::cout;
using std::endl;
using std::vector;
#define endl '\n' // 交互题记得去掉

void solve()
{
    // std::cout << std::fixed << std::setprecision(2);
    // std::cout.unsetf(std::ios::fixed);

    int N;
    cin >> N;

    vector<int> val(N + 1, 0);
    vector<int> lson(N + 1, 0), rson(N + 1, 0);

    for (int i = 1; i <= N; i ++) {
        int x;
        cin >> x;
        val[x] = i;
    }

    std::stack<int> stk;

    for (int i = 1; i <= N; i ++) {
        int last = 0;

        while (stk.size() && val[stk.top()] > val[i]) {
            last = stk.top();
            stk.pop();
        }

        if (stk.size()) {
            rson[stk.top()] = i;
        }

        lson[i] = last;
        stk.push(i);
    }

    while (stk.size() > 1) stk.pop();

    int root = stk.top();

    auto dfs = [&](auto self, int now) -> void {
        cout << now << " ";
        if (lson[now]) self(self, lson[now]);
        if (rson[now]) self(self, rson[now]);
    };

    dfs(dfs, root);

    return;
}

int main()
{
    std::ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int _ = 1;
    // cin >> _;
    for (int i = 0; i < _; i ++)
    {
        solve();
    }
    return 0;
}
```

实现要点：

- `val[x] = i` 记录的是"键值 $x$ 的插入时间"，`val` 就是上面的 $t$，单调栈比较的也正是 `val`。
- 弹栈时只需保留最后一个 `last`：中间那些被弹掉的节点已经作为 `last` 子树的一部分被挂好了，不必单独处理。
- `while (stk.size() > 1) stk.pop();` 之后 `stk.top()` 就是栈底元素，即整棵树的根。
- 前序遍历写成递归 lambda（`auto self` 形式），最坏递归深度 $O(n)$；本题 $n\le10^5$，栈空间足够。

## 复杂度

- 时间复杂度：$O(n)$。单调栈建树中每个节点至多入栈、出栈各一次；前序遍历每个节点访问一次。
- 空间复杂度：$O(n)$：`val`、`lson`、`rson` 与栈各占 $O(n)$，前序递归深度最坏 $O(n)$。
