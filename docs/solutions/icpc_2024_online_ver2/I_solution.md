# I Strange Binary 题解

## 题意

通常的二进制分解写作 $n=\overline{a_{31}a_{30}\dots a_0}$，其中每个 $a_i\in\{0,1\}$。本题把系数集合放松成 $\{-1,0,1\}$，但要求相邻两位不能同时为 $0$。具体地，一个数组 $a_0,a_1,\dots,a_{31}$ 是 $n$ 的**奇怪二进制分解**，当且仅当

$$a_i\in\{-1,0,1\}\quad(0\le i\le 31),\qquad a_i^2+a_{i+1}^2\neq 0\quad(0\le i\le 30),\qquad \sum_{i=0}^{31}a_i2^i=n$$

给定非负整数 $n$，求出它的任意一个奇怪二进制分解，或者判定它不存在。

输入第一行是数据组数 $T$（$1\le T\le 10^4$），接下来 $T$ 行每行一个 $n$（$0\le n<2^{30}$）。每组数据输出一行 `YES` 或 `NO`；若是 `YES`，紧接着输出 $32$ 个整数 $a_0,a_1,\dots,a_{31}$，每行 $8$ 个，共 $4$ 行（第一行是 $a_0\dots a_7$，最后一行以 $a_{31}$ 结尾）。

样例中 $n=0$ 输出 `NO`；$n=3$ 的解是 $a_0=1$、$a_1=\dots=a_{30}=-1$、$a_{31}=1$；$n=5$ 的解是 $a_0=-1$、$a_1=1$、$a_2=\dots=a_{30}=-1$、$a_{31}=1$。两者都可以直接代入 $\sum a_i2^i$ 验证。

时限 $1$ 秒，内存 $256$ MB。

## 核心思路

**算法类型**：先对 $n$ 取模得到必要条件，再从高位到低位扫描二进制位，把每个 $1$ 位"下沉"成一段 $-1$，从而构造出解；最后检查数组中 $0$ 的个数来判断 $n$ 是否属于无解的那一类。

### 第一步：取模给出必要条件

把 $n=\sum_{i=0}^{31}a_i2^i$ 对 $2$ 取模，所有 $i\ge1$ 的项都被消掉：

$$n\equiv a_0\pmod 2$$

因为 $a_0\in\{-1,0,1\}$，而 $\pm1$ 都是奇数，$0$ 是偶数，所以：

- $n$ 是奇数时必须有 $a_0=\pm1$；
- $n$ 是偶数时必须有 $a_0=0$。

若 $n$ 是偶数，则 $a_0=0$；此时由"相邻不同时为 $0$"得到 $a_1\neq0$，即 $a_1=\pm1$。再把 $n$ 对 $4$ 取模，把 $a_0=0$ 代进去：

$$n=2a_1+4\sum_{i=2}^{31}a_i2^{i-2}\equiv 2a_1\equiv 2\pmod 4$$

也就是说，偶数 $n$ 只有 $n\equiv2\pmod 4$ 才可能分解成功，凡是 $4\mid n$ 的 $n$ 一律无解——$n=0$ 正好落在这一类里，和样例第一组输出 `NO` 吻合。

这条推理同时暗示了完整的判据：$4\mid n$ 输出 `NO`，否则输出 `YES`。下面用构造把充分性也补上。

### 第二步：把一个 $1$ 位下沉成一段 $-1$

记 $n$ 的二进制第 $i$ 位为 $n_i$。构造依赖一条恒等式：对 $0\le i\le h-2\le 31$，

$$2^{h-1}-\sum_{j=i}^{h-2}2^j=2^{h-1}-\left(2^{h-1}-2^i\right)=2^i$$

解读是：**在位置 $h-1$ 放一个 $+1$，把它下面直到位置 $i$ 的连续一段全放成 $-1$，这一"块"的净贡献恰好是 $2^i$**。取 $h=32$ 时它变形为题解常用的那条式子

$$2^{31}-\sum_{j=i}^{30}2^j=2^i$$

于是做法非常自然：从高位到低位扫描 $n$（$n<2^{30}$，所以第 $31$ 位恒为 $0$，实际扫描第 $30$ 位到第 $0$ 位即可）。维护一个指针 $h$，初值 $h=32$，含义是"当前块要占用位置 $h-1$ 放那个 $+1$"。每当遇到一个为 $1$ 的位 $i$：

1. 令 $a_{h-1}=+1$；
2. 令 $a_{h-2}=a_{h-3}=\dots=a_i=-1$；
3. 令 $h\leftarrow i$，表示下一个块的天花板降到了这里。

每个 $1$ 位恰好触发一次，所以块数等于 $n$ 的二进制中 $1$ 的个数。若这些 $1$ 位从高到低是 $i_1>i_2>\dots>i_k$，那么第 $t$ 个块覆盖的区间是 $[i_t,\ i_{t-1}-1]$（约定 $i_0-1=31$），每个块内部的取值是"顶端 $+1$、其余 $-1$"。由恒等式，第 $t$ 块贡献 $2^{i_t}$，累加起来

$$\sum_{t=1}^{k}2^{i_t}=\sum_{i:\,n_i=1}2^i=n$$

最后一块贡献的是 $2^{i_k}$，正好是 $n$ 的最低位那个 $1$。所以这个构造出来的数组在数值上一定等于 $n$，永远不会算错。

### 第三步：$0$ 出现在哪里，条件二是否满足

块区间清单是

$$[i_1,31],\quad [i_2,i_1-1],\quad [i_3,i_2-1],\quad \dots,\quad [i_k,i_{k-1}-1]$$

它们两两不交，并集是 $[i_k,31]$。所以最终数组里：

- 位置 $i_k,i_k+1,\dots,31$ 都被某个块写过，值只能是 $+1$ 或 $-1$，一定非 $0$；
- 位置 $0,1,\dots,i_k-1$ 从头到尾没有被任何块碰到，保持初始值 $0$。

记 $p=i_k$ 为 $n$ 的最低非零二进制位，则数组中恰好有 $p$ 个 $0$，位置是 $0,1,\dots,p-1$。分三种情况：

- $p=0$（$n$ 是奇数）：一个 $0$ 都没有，相邻不同时为 $0$ 自动成立；
- $p=1$（$n\equiv2\pmod 4$）：唯一的 $0$ 在位置 $0$，而 $a_1=-1\neq0$，条件成立；
- $p\ge2$（$4\mid n$）：$a_0=a_1=0$，条件二被违反，这个 $n$ 确实无解。

这与第一步的必要条件严格互补：**有解当且仅当 $4\nmid n$**。$4\nmid n$ 时上面的贪心构造给出合法解（最低非零位 $p=0$ 或 $p=1$，数组里至多一个 $0$）；$4\mid n$（含 $n=0$）时无解，输出 `NO`。

代码正是这样落地的：构造完成后数一遍数组中 $0$ 的个数 `tot`，`tot > 1` 就说明最低非零位 $p\ge2$、即 $4\mid n$，输出 `NO`；否则输出 `YES` 并打印整个数组。$n>0$ 时 `tot` 恰好等于 $p$，$n=0$ 时数组全为 $0$、`tot = 32`，同样被判为 `NO`。

### 小例子

$n=5=(101)_2$，为 $1$ 的位是 $i=2$ 和 $i=0$：

| 扫描到 | $h$ | 写入 | 写入后的 $h$ |
| --- | --- | --- | --- |
| $i=2$，位为 $1$ | $32$ | $a_{31}=1$，$a_{30}\dots a_2=-1$ | $2$ |
| $i=1$，位为 $0$ | $2$ | 不写 | $2$ |
| $i=0$，位为 $1$ | $2$ | $a_1=1$，$a_0=-1$ | $0$ |

结果 $a_0=-1$、$a_1=1$、$a_2\dots a_{30}=-1$、$a_{31}=1$，与样例第二组输出一致。代入得 $-1+2-\left(2^2+2^3+\dots+2^{30}\right)+2^{31}=-1+2-(2^{31}-4)+2^{31}=5$，正确。

同理 $n=3=(11)_2$：先处理 $i=1$ 得到 $a_{31}=1$、$a_{30}\dots a_1=-1$，再处理 $i=0$ 得到 $a_0=1$，总和 $1-(2^{31}-2)+2^{31}=3$，与样例第一组 `YES` 的输出完全一致。而 $n=4$ 时会得到 $a_0=a_1=0$，代码输出 `NO`。

### 实现要点

- `arr` 是长度 $32$、初值全 $0$ 的数组；`head` 即上面的 $h$，初值 $32$；`tail` 是当前扫描到的二进制位，初值 $31$。
- 命中一个 $1$ 位时，先写 `arr[head - 1] = 1` 并 `head --`，再用内层 `while (head > tail)` 一路把 `arr[head]` 置为 $-1$。循环结束时 `head` 恰好等于 `tail`，也就是本次的 $1$ 位位置，正好作为下一个块的 $h$。
- `head - 1` 最大取到 $31$（$h$ 初值 $32$），而 $n<2^{30}$ 时第一个命中的 $1$ 位 $i_1\le29$，块 $[i_1,31]$ 非空，不会发生下标越界。
- 外层循环条件是 `tail >= 0 && head >= tail`。由于每处理完一个 $1$ 位就有 `head` 等于该位、而 `tail` 总是严格更小，`head >= tail` 恒成立，这个条件不会导致提前退出，效果等价于 `tail >= 0`。
- 判断某一位是否为 $1$ 的表达式写作 `(n >> tail) & 1 == 1`。在 C++ 中 `==` 的优先级高于 `&`，它被解析成 `(n >> tail) & (1 == 1)`，即 `(n >> tail) & 1`，与"取最低位"的意图相同，结果正确。
- 输出格式为 $4$ 行、每行 $8$ 个数，代码用 `i * 8 + j` 顺序打印 `arr[0..31]`，行尾多一个空格不影响判题。

#define LL long long
#define ULL unsigned long long

#define pair_LL std::pair<LL, LL>
const int INF_INT = 0x3f3f3f3f;

void solve()
{
    // std::cout << std::fixed << std::setprecision(2);
    // std::cout.unsetf(std::ios::fixed);
    LL n;
    cin >> n;

    vector<int> arr(32, 0);

    int head = 32, tail = 31;

    while (tail >= 0 && head >= tail) {
        if ((n >> tail) & 1 == 1) {
            arr[head - 1] = 1;
            head --;
            while (head > tail) {
                head --;
                arr[head] = -1;
            }
        }
        tail --;
    }

    int tot = 0;
    for (int i = 0; i < 32; i ++) {
        if (arr[i] == 0) tot ++;
    }

    if (tot > 1) {
        cout << "NO" << endl;
    }
    else {
        cout << "YES" << endl;
        for (int i = 0; i < 4; i ++) {
            for (int j = 0; j < 8; j ++) {
                int now = i * 8 + j;
                cout << arr[now] << " ";
            }
            cout << endl;
        }
    }
    return;
}

int main()
{
    std::ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
    int _ = 1;
    cin >> _;
    for (int i = 0; i < _; i ++)
    {
        solve();
    }
    return 0;
}

## 复杂度

- 时间复杂度：$O(32)$ 每组。外层扫描 $32$ 个二进制位，内层 `-1` 的写入总量是每个位置至多一次、合计不超过 $32$ 次，最后再扫一遍数组数 $0$；$T$ 组数据总计 $O(32T)$，即约 $3.2\times10^5$ 次基本操作，远小于 $1$ 秒的时限。
- 空间复杂度：$O(1)$，只有长度 $32$ 的 `arr` 和常数个整型变量，与 $T$ 无关。
